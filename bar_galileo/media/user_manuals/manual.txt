¿Qué es la página Web Bar Galileo?

Bar Galileo es una aplicación web para la gestión integral de un bar/restaurante. Incluye los siguientes módulos: mesas y pedidos, inventario de productos, categorías, marcas, proveedores, facturación, gastos, nóminas y empleados, reportes (PDF/Excel/CSV), notificaciones en tiempo real, backups, gestión de usuarios y roles con permisos, panel de usuario personal, gestión de imágenes del sitio web, un asistente con IA para consultar documentos (RAG) y un chat de inteligencia artificial general.

Los módulos descritos en este manual corresponden a las funcionalidades implementadas en el sistema.

1. ACCESO AL SISTEMA E INICIO DE SESIÓN
════════════════════════════════════════════════════════════════

El sistema se accede desde un navegador web. La URL depende del entorno:
   • Desarrollo local: http://localhost:8000
   • Producción/Docker: la URL configurada por el administrador del servidor.

Pasos para iniciar sesión:

   • Paso 1. En el campo Usuario, escribe tu nombre de usuario.
   • Paso 2. En el campo Contraseña, escribe tu clave (respeta mayúsculas/minúsculas).
   • Paso 3. Completa el captcha de verificación.
   • Paso 4. Presiona el botón "Iniciar sesión".
   • Paso 5. Si prefieres ingresar con tu cuenta de Google, presiona el botón "Ingresar con Google".

[IMAGEN: Pantalla de inicio de sesión con campos usuario, contraseña, captcha y botón de Google]


────────────────────────────────────────────────────────────────
1.1 Restablecer contraseña
────────────────────────────────────────────────────────────────

Si olvidaste tu contraseña:

   • Paso 1. En la pantalla de login, presiona "¿Olvidaste tu contraseña?".
   • Paso 2. Ingresa tu correo electrónico registrado.
   • Paso 3. Presiona "Restablecer Contraseña".
   • Paso 4. Revisa tu bandeja de entrada (y spam) para el enlace de recuperación.
   • Paso 5. Sigue el enlace y crea una nueva contraseña.

Usa "Volver al inicio de sesión" para regresar sin realizar cambios.

[IMAGEN: Formulario de restablecimiento de contraseña]

Al ingresar verás el panel de estadísticas generales que muestra un resumen visual del estado del sistema:

Esta sección es solo de consulta y no permite realizar acciones directas.

   • PDF: documento con formato para impresión.

Para exportar, busca los botones de exportación en la parte superior del dashboard y selecciona el formato deseado.


────────────────────────────────────────────────────────────────

Para acceder al listado completo de módulos, haz clic en el icono de menú (☰) en la parte superior izquierda. Se desplegará el panel lateral con acceso a todos los módulos disponibles según tu rol y permisos.

Nota: Los módulos visibles dependen de los permisos asignados a tu rol. Si no ves un módulo, contacta al administrador.

3. MÓDULO: MESAS Y PEDIDOS
════════════════════════════════════════════════════════════════

Este módulo se usa para la operación diaria: abrir mesas, tomar pedidos, enviar a preparación y facturar.

[IMAGEN: Vista general de mesas]


────────────────────────────────────────────────────────────────
3.1 Ver mesas
────────────────────────────────────────────────────────────────

La vista principal muestra todas las mesas registradas con su estado actual. Los estados posibles son:

   • Disponible: mesa libre, lista para recibir clientes.
   • Ocupada: mesa con un pedido activo en proceso.
   • Reservada: mesa apartada para un cliente.
   • Fuera de servicio: mesa no disponible (mantenimiento, etc.).

Cada mesa se muestra con un color diferente según su estado para fácil identificación visual.


────────────────────────────────────────────────────────────────
3.2 Crear mesa
────────────────────────────────────────────────────────────────

   • Paso 1. Presiona el botón "Crear mesa" o "+".
   • Paso 2. Ingresa el nombre de la mesa (ej.: "Mesa 1", "Terraza 3").
   • Paso 3. Agrega una descripción opcional (ej.: "Mesa junto a la ventana").
   • Paso 4. Selecciona el estado inicial de la mesa.
   • Paso 5. Presiona "Guardar".

Usa "Volver" para regresar sin guardar cambios.

[IMAGEN: Formulario de crear mesa]


────────────────────────────────────────────────────────────────
3.3 Editar mesa
────────────────────────────────────────────────────────────────

   • Paso 1. En la lista de mesas, selecciona la mesa que deseas editar.
   • Paso 2. Presiona el botón "Editar".
   • Paso 3. Modifica el nombre, descripción o estado según necesites.
   • Paso 4. Presiona "Guardar" para confirmar los cambios.

Para eliminar una mesa, presiona "Eliminar". El sistema pedirá confirmación antes de proceder.

Nota: No se puede eliminar una mesa que tenga un pedido activo.


────────────────────────────────────────────────────────────────
3.4 Cambiar estado / Liberar mesa
────────────────────────────────────────────────────────────────

   • Cambiar estado: Puedes cambiar directamente el estado de una mesa (disponible, ocupada, reservada, fuera de servicio) desde la vista de mesas.
   • Liberar mesa: Cuando una mesa está ocupada y ya se facturó el pedido, usa el botón "Liberar" para cambiarla a estado disponible.


────────────────────────────────────────────────────────────────
3.5 Agregar productos al pedido
────────────────────────────────────────────────────────────────

   • Paso 1. Selecciona una mesa disponible u ocupada.
   • Paso 2. Presiona "Pedido" para abrir el panel de pedido.
   • Paso 3. Busca el producto por nombre o categoría.
   • Paso 4. Selecciona la cantidad deseada.
   • Paso 5. Presiona "Agregar" para añadirlo al pedido.
   • Paso 6. Repite para cada ítem (bebidas, cócteles, comida, etc.).
   • Paso 7. Puedes modificar la cantidad o eliminar ítems del pedido en cualquier momento.
   • Paso 8. Revisa el total provisional del pedido en la parte inferior.

Las actualizaciones de stock se reflejan en tiempo real gracias al sistema de WebSockets.

[IMAGEN: Panel de pedido con productos agregados]


────────────────────────────────────────────────────────────────
3.6 Asignar usuarios al pedido
────────────────────────────────────────────────────────────────

Puedes asignar uno o más usuarios (meseros) a un pedido para llevar registro de quién atendió cada mesa:

   • Paso 1. Dentro del pedido activo, busca la opción de gestión de usuarios.
   • Paso 2. Selecciona el o los usuarios que atienden la mesa.
   • Paso 3. Confirma la asignación.


────────────────────────────────────────────────────────────────
3.7 Facturar y cerrar mesa
────────────────────────────────────────────────────────────────

   • Paso 1. Confirma que todos los productos consumidos estén registrados en el pedido.
   • Paso 2. Presiona el botón "Facturar".
   • Paso 3. El sistema genera automáticamente una factura con un número único de 8 dígitos.
   • Paso 4. Se muestra la factura con el detalle de productos, cantidades, precios y total.
   • Paso 5. La mesa queda lista para ser liberada.

Nota: Una vez facturado, el pedido no se puede modificar.

[IMAGEN: Factura generada]

4. MÓDULO: PRODUCTOS E INVENTARIO
════════════════════════════════════════════════════════════════

Aquí se administran los productos del bar, incluyendo precios, stock e imágenes.

[IMAGEN: Lista de productos]


────────────────────────────────────────────────────────────────
4.1 Lista de productos
────────────────────────────────────────────────────────────────

La vista principal muestra todos los productos activos en formato de tabla con:
   • Nombre del producto
   • Categoría
   • Marca
   • Proveedor
   • Precio de venta
   • Stock disponible
   • Estado (activo/archivado)

Puedes usar el buscador y los filtros para encontrar productos específicos.


────────────────────────────────────────────────────────────────
4.2 Crear un producto
────────────────────────────────────────────────────────────────

   • Paso 1. En la lista de productos, presiona "+ Crear producto".
   • Paso 2. Completa los campos del formulario:
      - Nombre: nombre del producto (debe ser único).
      - Categoría: selecciona la categoría (ej.: Bebidas, Cócteles, Comida).
      - Marca: selecciona la marca del producto.
      - Proveedor: selecciona el proveedor.
      - Precio de compra: costo de adquisición del producto.
      - Precio de venta: precio al que se vende al cliente.
      - Stock: cantidad inicial disponible.
      - Descripción: descripción opcional del producto.
      - Imágenes: sube una o más imágenes del producto.
   • Paso 3. Presiona "Guardar".

Nota: El precio de venta debe ser mayor al precio de compra. El sistema valida esto automáticamente.

Nota: Las imágenes se convierten automáticamente a formato WEBP optimizado.

[IMAGEN: Formulario de crear producto]


────────────────────────────────────────────────────────────────
4.3 Editar un producto
────────────────────────────────────────────────────────────────

   • Paso 1. En la tabla de productos, busca el producto usando el buscador o filtros.
   • Paso 2. En la columna de acciones, presiona "Editar".
   • Paso 3. Modifica los campos que necesites (precio, stock, nombre, imágenes, etc.).
   • Paso 4. Presiona "Guardar" para confirmar los cambios.

También puedes agregar o eliminar imágenes del producto desde la vista de edición.


────────────────────────────────────────────────────────────────
4.4 Eliminar (archivar) un producto
────────────────────────────────────────────────────────────────

   • Paso 1. En la tabla de productos, busca el producto.
   • Paso 2. En la columna de acciones, presiona "Eliminar".
   • Paso 3. Confirma la acción.

Importante: Eliminar un producto NO lo borra permanentemente del sistema. El producto se archiva (desactivación lógica) y deja de aparecer en la lista de productos activos y en los pedidos.


────────────────────────────────────────────────────────────────
4.5 Productos archivados y reactivación
────────────────────────────────────────────────────────────────

   • Paso 1. Accede a la sección "Productos archivados" desde el menú de productos.
   • Paso 2. Verás la lista de productos que fueron eliminados/archivados.
   • Paso 3. Para reactivar un producto, presiona "Reactivar" en la columna de acciones.
   • Paso 4. El producto volverá a aparecer en la lista de productos activos.


────────────────────────────────────────────────────────────────
4.6 Ajustes de inventario (entradas/salidas)
────────────────────────────────────────────────────────────────

   • Usa "Ajuste de inventario" cuando haya conteos físicos, pérdidas o correcciones.
   • Registra el motivo del ajuste (ej.: merma, daño, conteo, devolución).
   • Para compras a proveedor, registra como Entrada. Para consumo o merma, como Salida.
   • Verifica el stock final y guarda.

El sistema mantiene un historial de todos los movimientos de stock con fecha y hora.

   • Antigüedad en el bar

20. SOLUCIÓN DE PROBLEMAS (FAQ)
════════════════════════════════════════════════════════════════

PROBLEMA: No puedo iniciar sesión.
SOLUCIÓN: Verifica que usuario y contraseña sean correctos (respeta mayúsculas). Tu cuenta puede estar desactivada o el servidor puede estar fuera de línea. Contacta al administrador.

PROBLEMA: No veo un módulo en el menú.
SOLUCIÓN: Tu rol no tiene permiso para acceder a ese módulo. Solicita al administrador que revise los permisos de tu rol.

PROBLEMA: No puedo generar un reporte (PDF/Excel/CSV).
SOLUCIÓN: Verifica que tengas permisos de reportes. Asegúrate de que el rango de fechas tenga datos. Si persiste, contacta al administrador.

PROBLEMA: No llegan las notificaciones.
SOLUCIÓN: Recarga la página para restablecer la conexión WebSocket. Verifica tu conexión a internet. Si persiste, el servicio WebSocket puede estar detenido (contactar al administrador).

PROBLEMA: El inventario no cuadra con el stock físico.
SOLUCIÓN: Realiza un conteo físico y registra un ajuste de inventario con el motivo correspondiente (merma, daño, conteo).

PROBLEMA: El chat IA no responde o da errores.
SOLUCIÓN: Verifica que la API key de Google Gemini esté configurada correctamente. Para el chat RAG, asegúrate de tener al menos un documento subido y procesado.

PROBLEMA: No puedo crear o restaurar un backup.
SOLUCIÓN: Verifica que tienes permisos de administrador. Asegúrate de que hay espacio disponible en el servidor. Si usas encriptación GPG, verifica que las claves estén configuradas.

PROBLEMA: Las imágenes no se muestran correctamente.
SOLUCIÓN: Verifica que la carpeta /media/ tenga los permisos correctos. Intenta subir la imagen nuevamente.

PROBLEMA: El sistema está lento.
SOLUCIÓN: Puede deberse a la conexión a internet o a la carga del servidor. Intenta recargar la página. Si persiste, contacta al administrador para revisar los recursos del servidor.

XX. MÓDULO: FILTRO AVANZADO DE BÚSQUEDA
════════════════════════════════════════════════════════════════

Este módulo permite filtrar registros usando condiciones personalizadas. Puedes combinar
múltiples criterios (por ejemplo: precio, stock, categoría) con operadores lógicos AND/OR
para obtener resultados exactos.

[IMAGEN: Vista general del filtro avanzado]


────────────────────────────────────────────────────────────────
XX.1 Partes del filtro
────────────────────────────────────────────────────────────────

El filtro está compuesto por los siguientes elementos:

   • Botón AND / OR (parte superior): define cómo se combinan TODAS las condiciones del
     filtro entre sí.
      - AND: se muestran solo los registros que cumplen TODAS las condiciones.
      - OR: se muestran los registros que cumplen AL MENOS UNA condición.

   • Fila de condición: cada condición tiene tres campos:
      - Data (campo rojo): el dato a evaluar (ej.: Precio, Stock, Categoría, Nombre).
      - Condición (campo verde): el tipo de comparación (ej.: igual a, menor a, mayor a,
        contiene, entre).
      - Valor (campo azul): el valor con el que se compara (ej.: 5000, "Bebidas", 10).

   • Botón X: elimina esa condición del filtro.

   • Botón "Añadir condición": agrega una nueva fila de condición al filtro.

[IMAGEN: Fila de condición con los campos Data, Condición y Valor]


────────────────────────────────────────────────────────────────
XX.2 Crear un filtro simple (una condición)
────────────────────────────────────────────────────────────────

   • Paso 1. Accede al módulo donde deseas filtrar (ej.: Productos, Facturación, Gastos).
   • Paso 2. Presiona el botón "Filtro" o "Filtro avanzado".
   • Paso 3. En el campo Data, selecciona el dato que quieres evaluar (ej.: "Precio").
   • Paso 4. En el campo Condición, selecciona el tipo de comparación (ej.: "Menor a").
   • Paso 5. En el campo Valor, escribe el valor de referencia (ej.: 10000).
   • Paso 6. Presiona "Aplicar" o "Buscar" para ver los resultados.

Ejemplo: mostrar todos los productos con precio menor a 10.000.

[IMAGEN: Filtro simple con una condición configurada]


────────────────────────────────────────────────────────────────
XX.3 Agregar múltiples condiciones
────────────────────────────────────────────────────────────────

   • Paso 1. Configura la primera condición siguiendo los pasos del apartado XX.2.
   • Paso 2. Presiona el botón "Añadir condición".
   • Paso 3. Aparecerá una nueva fila con sus propios campos Data, Condición y Valor.
   • Paso 4. Completa los campos de la nueva condición (ej.: Data: "Stock", Condición:
     "Mayor a", Valor: "5").
   • Paso 5. Repite los pasos 2 al 4 para agregar más condiciones si lo necesitas.
   • Paso 6. Presiona "Aplicar" para ver los resultados.

Ejemplo: mostrar productos con precio menor a 10.000 Y stock mayor a 5.

[IMAGEN: Filtro con dos condiciones y operador AND seleccionado]


────────────────────────────────────────────────────────────────
XX.4 Cambiar el operador lógico (AND / OR)
────────────────────────────────────────────────────────────────

Cuando tienes más de una condición, el botón AND/OR en la parte superior del filtro
determina cómo se relacionan entre sí:

   • AND: el resultado mostrará solo los registros que cumplan TODAS las condiciones al
     mismo tiempo.
      Ejemplo: precio menor a 10.000 AND stock mayor a 5 → muestra productos baratos
      que además tienen stock suficiente.

   • OR: el resultado mostrará los registros que cumplan al menos UNA de las condiciones.
      Ejemplo: precio menor a 10.000 OR stock mayor a 5 → muestra productos baratos
      o productos con buen stock (o ambos).

Para cambiar el operador, presiona el botón "AND" u "OR" en la parte superior del filtro.
El botón activo cambiará de apariencia para indicar cuál está seleccionado.


────────────────────────────────────────────────────────────────
XX.5 Eliminar una condición
────────────────────────────────────────────────────────────────

   • Paso 1. Identifica la fila de la condición que deseas eliminar.
   • Paso 2. Presiona el botón "X" ubicado al lado derecho de esa fila.
   • Paso 3. La condición desaparecerá inmediatamente.

Nota: Si eliminas todas las condiciones, el filtro quedará vacío y se mostrarán todos
los registros sin filtrar.


────────────────────────────────────────────────────────────────
XX.6 Limpiar el filtro
────────────────────────────────────────────────────────────────

Para remover todos los filtros y ver todos los registros nuevamente:

   • Presiona el botón "Limpiar filtro" o "Restablecer".
   • También puedes eliminar cada condición individualmente con su botón X.

XX.7 Ejemplos de uso
────────────────────────────────────────────────────────────────

Ejemplo 1 – Productos con stock bajo:
   • Data: Stock | Condición: Menor a | Valor: 5
   → Muestra productos que necesitan reabastecimiento.

Ejemplo 2 – Facturas de un rango de fechas específico:
   • Data: Fecha | Condición: Mayor a | Valor: 01/01/2026
   • Añadir condición → Data: Fecha | Condición: Menor a | Valor: 31/01/2026
   • Operador: AND
   → Muestra solo las facturas del mes de enero 2026.

Ejemplo 3 – Productos de dos categorías diferentes:
   • Data: Categoría | Condición: Igual a | Valor: Bebidas
   • Añadir condición → Data: Categoría | Condición: Igual a | Valor: Cócteles
   • Operador: OR
   → Muestra productos que sean Bebidas o Cócteles.
